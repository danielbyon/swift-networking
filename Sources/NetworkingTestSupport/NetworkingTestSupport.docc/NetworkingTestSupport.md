# ``NetworkingTestSupport``

Test real `NetworkClient` request construction and policy behavior with a deterministic mock transport. This product never falls through to live networking.

For endpoint construction and the async client entry point, see the [Networking Getting Started guide](https://github.com/danielbyon/swift-networking/blob/main/Sources/Networking/Networking.docc/GettingStarted.md).
